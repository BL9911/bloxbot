# bloxbot
Discord bot that displays statistics and trends from Roblox using a public API/

MVP Scope: Discord bot that can display data from a certain Roblox game given its ID number

Future plans: 
- make discord embeds more appealing
- automatic polling
- historical logging of data

Tech Stack:
- Python (main logic)
- Bash (startup script)
- discord.py (to connect to Discord)
- requests (to pull Roblox data)
- python-dotenv (to keep Roblox token in env file)
- Roblox public API
- Discord API
